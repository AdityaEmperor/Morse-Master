# Morse-Master
An Iot project to communicate in morse code and also message using internet

Step1 - Make connections as per the Diagram <br>
Step2 - Create template on blynk and paste its ID , Token and authorisation string in the source Code <br>
Step3 - Upload the source Code on Arduino board <br>
Step4 - In your pc , open terminal and run the Blynk Ser Script , this will now transfer your messages and show them on blynk terminal on other device<br>
